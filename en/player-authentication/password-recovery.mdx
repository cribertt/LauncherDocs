# Password recovery

Launcher Forge has two separate password recovery flows:

<CardGroup cols={2}>
  <Card title="Launcher player account" icon="gamepad">
    Uses a temporary OTP code sent by email.
  </Card>

  <Card title="Developer dashboard account" icon="user-gear">
    Uses a password reset link containing a temporary token.
  </Card>
</CardGroup>

## Launcher player account

Players recover their password directly from the launcher.

<Steps>
  <Step title="Request a recovery code">
    Enter the email address registered in the launcher and select **Send code**.
  </Step>

  <Step title="Check the email">
    Launcher Forge sends a temporary OTP recovery code.
  </Step>

  <Step title="Enter the code and new password">
    Paste the recovery code, enter the new password, and select **Reset password**.
  </Step>

  <Step title="Return to sign-in">
    After the password is updated, Launcher Forge sends a confirmation email and the player can sign in with the new password.
  </Step>
</Steps>

## Developer dashboard account

Developer accounts use a different recovery process.

<Steps>
  <Step title="Request reset instructions">
    Enter the developer account email and select **Send instructions**.
  </Step>

  <Step title="Open the reset email">
    Launcher Forge sends a password reset link containing a temporary token.
  </Step>

  <Step title="Set a new password">
    Open the link, enter and confirm the new password, and save it.
  </Step>

  <Step title="Sign in again">
    After the password is updated, Launcher Forge sends a confirmation email.
  </Step>
</Steps>
