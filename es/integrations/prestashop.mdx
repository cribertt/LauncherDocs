# Integración con PrestaShop

<Info>
Próximamente
</Info>

El módulo planificado de PrestaShop utilizará el mismo endpoint estable de Commerce API:

```text
POST /external/commerce/deliveries
```

Flujo planificado:

- Instalar el módulo de LauncherForge.
- Guardar la Commerce API key completa.
- Vincular productos de PrestaShop con App IDs de LauncherForge.
- Generar keys después de una orden pagada.
- Guardar las entregas en la orden.
- Mostrar las keys en la cuenta y el correo del cliente.
- Usar idempotencia determinística para evitar duplicados.

No publiques instrucciones de instalación hasta que el módulo esté implementado y probado.
