# Autenticación de la CLI

La autenticación utiliza menús y prompts.

```text
Launcher Forge CLI

❯ Subir una build
  Ver estado de carga
  Listar versiones
  Administrar permisos
  Cerrar sesión
  Mostrar versión de la CLI
```

Las cuentas creadas con OAuth pueden necesitar establecer una contraseña de Launcher Forge.
