# What is Launcher Forge?

Launcher Forge is a platform for creating branded desktop launchers, publishing game builds, distributing updates, and authenticating players without building the complete delivery infrastructure from scratch.

## Problems it solves

<CardGroup cols={2}>
  <Card title="Custom launchers" icon="rocket">Configure launcher identity, templates, and content.</Card>
  <Card title="Game distribution" icon="download">Publish packaged games through a desktop launcher.</Card>
  <Card title="Build management" icon="boxes-stacked">Organize versions, branches, manifests, patches, and hotfixes.</Card>
  <Card title="Player authentication" icon="shield-halved">Validate players who start the game through Launcher Forge.</Card>
  <Card title="Engine integrations" icon="gamepad">Connect supported engines such as Unreal Engine.</Card>
  <Card title="Workspace controls" icon="gauge-high">Manage limits, usage, plans, and team access.</Card>
</CardGroup>

## Typical workflow

<Steps>
  <Step title="Create a launcher">Choose a template and configure its identity.</Step>
  <Step title="Add a game">Register metadata, images, and the executable.</Step>
  <Step title="Package the game">Produce and test the final runtime build.</Step>
  <Step title="Publish with the interactive CLI">Follow guided menus for game, branch, version, release type, folder, and changelog.</Step>
  <Step title="Test the launcher">Install, update, and start the game.</Step>
</Steps>
