# Add your first game

Games are created and managed from the **Catalog** section of the Launcher Forge dashboard.

Because each account currently uses one workspace and one launcher, every game created in the Catalog belongs to that workspace and can be displayed in the existing launcher after it is published.

<Warning>
  Every new game is created as a **Draft** by default. A draft is not public and does not appear in the launcher for players.
</Warning>

To make the game visible, you must create it first, open its edit panel, change its publishing status to **Published**, and save the changes.

## Before you begin

Prepare the following information:

- The public game name.
- A description of the game.
- One or more genres.
- A cover image.
- A packaged game build for a later step.

The build is not uploaded during game creation. Builds are published separately with the Launcher Forge interactive CLI.

## 1. Open the Catalog

Sign in to the Launcher Forge dashboard.

In the left sidebar, locate **MY GAMES** and select **Catalog**.

The Catalog displays:

- Total games.
- Published games.
- Draft games.
- Archived games.
- Search and status filters.

Select **New Game** in the upper-right corner.

## 2. Complete the initial game information

Launcher Forge opens the **Create new game** page.

The game is created as a draft, as indicated by the message:

```text
It will be created as a draft
```

Complete the available fields.

### Game name

Enter the public name that players will see in the launcher.

Use a recognizable final name. You can edit it later.

### Description

Describe the game, its universe, mechanics, or main proposition.

The form supports up to `500` characters for this initial description.

### Genres

Select the genres that best represent the game.

Available examples include:

- RPG.
- Action.
- Adventure.
- Strategy.
- Puzzle.
- Simulation.
- Sports.
- Horror.
- Indie.

### Game cover

The cover image is optional during the initial creation step, but adding one is recommended.

The interface accepts:

- PNG.
- JPG.
- WEBP.
- GIF.

The maximum file size displayed by the form is `10 MB`.

Launcher Forge recommends a `1920 × 1080` image for better visibility in the launcher.

  <img

<Note>
  The game name and at least one genre are required. The cover is optional, but it improves how the game appears in the launcher.
</Note>

## 3. Create the game

After completing the required fields, submit the form.

Launcher Forge creates the game and returns it to the Catalog.

The newly created game appears with the **Draft** status.

<Info>
  Draft means the game exists in your workspace, but only you can see it in the developer dashboard. Players cannot see it in the launcher yet.
</Info>

## 4. Open the game editor

Locate the game card in the Catalog.

Move the pointer over the card and select the pencil icon labeled **Edit game**.

<Frame caption="Open the draft game using the Edit game button">
  <img
    src="/images/screenshots/draft-game-edit.png"
    alt="Draft game card in Launcher Forge with the Edit game button highlighted"
  />
</Frame>

The editor allows you to review and update the game information before making it public.

## 5. Open the Publishing tab

Inside the game editor, select the **Publishing** tab.

<Frame caption="Open the Publishing tab in the game editor">
  <img
    src="/images/screenshots/game-publishing-tab.png"
    alt="Launcher Forge game editor with the Publishing tab highlighted"
  />
</Frame>

The Publishing tab provides three statuses:

| Status | Behavior |
| --- | --- |
| **Published** | Visible in the launcher to everyone with access. |
| **Draft** | Visible only to you in the developer dashboard. |
| **Archived** | Hidden from the launcher. |

## 6. Publish the game

Select **Published**.

Then select **Save changes**.

<Frame caption="Select Published and save the changes">
  <img
    src="/images/screenshots/publish-game-save.png"
    alt="Launcher Forge Publishing tab with Published and Save changes highlighted"
  />
</Frame>

After saving:

- The game stops being a draft.
- The game appears in the **Published** filter.
- The published counter increases.
- The game becomes visible in the launcher.

<Warning>
  Selecting Published is not enough by itself. You must also select **Save changes** or the new status will not be applied.
</Warning>

## Draft, Published, and Archived

<Tabs>
  <Tab title="Draft">
    Use Draft while the game information is incomplete or while you are preparing its images, configuration, branches, and first build.

    Draft games are not visible to players.
  </Tab>

  <Tab title="Published">
    Use Published when the game is ready to appear in the launcher.

    Publishing the game makes its catalog entry visible, but it does not upload a game build automatically.
  </Tab>

  <Tab title="Archived">
    Use Archived when the game should no longer appear in the launcher.

    Archiving does not mean deleting the game.
  </Tab>
</Tabs>

## Important: publishing the game is not the same as publishing a build

Changing the game status to **Published** controls its visibility in the launcher.

It does not:

- Upload the game files.
- Create a branch.
- Create a version.
- Publish a stable build, patch, or hotfix.
- Configure the game executable automatically.

Game builds are published separately through the Launcher Forge interactive CLI.

## Final verification

Before continuing, verify:

- The game appears in the Catalog.
- Its status is **Published**.
- The information is correct.
- A genre is selected.
- The cover is displayed correctly.
- The game appears in the launcher.
- You are ready to configure branches and publish a build.

<Check>
  Your game has been created and published successfully. It is now visible in the launcher, but it still needs a valid game build before players can install and run it.
</Check>
