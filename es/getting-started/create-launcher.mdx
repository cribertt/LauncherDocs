# Crear tu primer launcher

<Steps>
  <Step title="Abre Launchers">Ingresa a la sección **Launchers**.</Step>
  <Step title="Crea un launcher">Ingresa un nombre claro y un slug único.</Step>
  <Step title="Selecciona un template">Elige uno disponible para el plan.</Step>
  <Step title="Define el idioma">Selecciona el idioma principal.</Step>
  <Step title="Guarda">Crea el registro antes de configurar el contenido detallado.</Step>
</Steps>
