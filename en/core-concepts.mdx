# Core concepts

| Concept | Description |
| --- | --- |
| **Workspace** | Main container for launchers, games, members, billing, usage, and permissions. |
| **Launcher** | Desktop application used to install, update, and start games. |
| **Game** | Product with metadata, launch settings, branches, builds, and versions. |
| **Branch** | Release channel such as stable, beta, alpha, development, or private. |
| **Build** | Packaged runtime files scanned and uploaded by the CLI. |
| **Version** | Published game state identified by a version number and changelog. |
| **Storage** | Space used by uploaded game and build files. |
| **Bandwidth** | Data transferred during downloads and updates. |
