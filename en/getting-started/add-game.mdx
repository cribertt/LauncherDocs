# Add your first game

<Steps>
  <Step title="Open the launcher">Select the launcher that will distribute the game.</Step>
  <Step title="Create the game">Enter title, slug, description, and genre.</Step>
  <Step title="Add visual assets">Upload the cover and banner.</Step>
  <Step title="Configure the executable">Set the executable path relative to the installed build.</Step>
  <Step title="Save and verify">Confirm the game appears in the dashboard and CLI.</Step>
</Steps>
