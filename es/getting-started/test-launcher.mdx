# Probar tu launcher

Después de publicar la primera build, completa la configuración del launcher y prueba el mismo flujo que utilizarán tus jugadores.

Este proceso cubre:

1. Asignar el nombre definitivo al launcher.
2. Vincular el juego.
3. Elegir acceso gratuito o mediante key.
4. Generar el ejecutable del launcher.
5. Instalar el launcher.
6. Crear una cuenta de usuario final.
7. Adquirir o canjear el juego.
8. Descargar e iniciar el juego.

<Warning>
  Publicar una build no hace que el juego aparezca automáticamente dentro del launcher. También debes vincular el juego con el launcher.
</Warning>

## Antes de comenzar

Confirma lo siguiente:

- El launcher existe.
- Tiene el nombre definitivo que deseas distribuir.
- El juego está **Published** en el Catálogo.
- El juego tiene una build válida publicada.
- El ejecutable principal fue seleccionado correctamente durante la publicación mediante CLI.
- El juego está listo para ser vinculado.

## 1. Define el nombre definitivo del launcher

Abre el launcher desde el menú lateral.

Selecciona el icono de edición junto al nombre, ingresa el nombre definitivo y presiona **Save**.

El instalador de Windows generado utiliza la identidad configurada en esta página.

</Frame>

<Warning>
  Define el nombre antes de generar el instalador de Windows. Un instalador que ya fue generado conserva el nombre incrustado en el momento de su creación.
</Warning>

## Comportamiento del icono del ejecutable

El icono del launcher se sincroniza automáticamente mediante la configuración en runtime.

Esto significa que cambiar el icono configurado del launcher no requiere generar nuevamente todo el paquete para que el launcher en ejecución reciba la actualización.

El comportamiento disponible depende del plan activo:

- Los planes con soporte para icono personalizado pueden utilizar el archivo `.ico` configurado.
- Los planes sin esta función utilizan el icono oficial de Launcher Forge.

<Info>
  El icono del launcher se actualiza automáticamente mediante la configuración en runtime.
</Info>

<Warning>
  El icono incrustado dentro de un instalador de Windows que ya fue generado no se actualiza automáticamente. Elimina el instalador actual y genera uno nuevo si necesitas que el archivo de instalación utilice el nuevo icono.
</Warning>

En la sección de administración del launcher, selecciona **Linked games**.

## 3. Elige el tipo de acceso

Antes de vincular el juego, decide cómo obtendrán acceso los jugadores.

<Frame caption="Elige el tipo de acceso y vincula el juego">
  <img
    src="/images/screenshots/launcher-link-game-access.png"
    alt="Página Linked apps mostrando la opción Key y el botón Link"
  />
</Frame>

<Tabs>
  <Tab title="Acceso gratuito">
    Deja **Key** desactivado.

    El juego será tratado como gratuito dentro del launcher. Después de iniciar sesión, el usuario final podrá seleccionar **Acquire** para añadirlo a su cuenta.

    Utiliza este modo para:

    - Juegos gratuitos.
    - Demos públicas.
    - Pruebas abiertas.
    - Juegos que no requieren una compra.
  </Tab>

  <Tab title="Acceso mediante key">
    Activa **Key** antes de vincular el juego.

    El usuario deberá iniciar sesión y canjear una CD key válida antes de obtener acceso.

    Utiliza este modo para:

    - Juegos de pago.
    - Acceso controlado.
    - Distribuciones privadas.
    - Keys promocionales o de prueba.
    - Acceso vendido mediante tu propio flujo comercial.

    Genera y administra las keys desde la sección **CD Keys** de Launcher Forge.
  </Tab>
</Tabs>

<Info>
  Todos los usuarios del launcher deben autenticarse mediante una cuenta de usuario final. El modo Key añade el requisito de canje, pero no reemplaza la autenticación.
</Info>

## 4. Vincula el juego

Selecciona **Link**.

Después de completar la operación:

- Aumenta el contador de juegos vinculados.
- El juego muestra el estado **Linked**.
- La acción cambia a **Unlink**.
- El juego pasa a formar parte de la configuración del launcher.

<Frame caption="Confirma que el juego quedó vinculado">
  <img
    src="/images/screenshots/launcher-game-linked.png"
    alt="Página Linked apps mostrando el juego con estado Linked"
  />
</Frame>

<Warning>
  Desvincular el juego lo elimina de la biblioteca del launcher. No elimina el juego, sus builds ni sus versiones del workspace.
</Warning>

## ¿Se puede vincular después de generar el launcher?

Sí.

El launcher recibe la configuración de juegos vinculados y contenido mediante actualizaciones en runtime. Puedes vincular o desvincular un juego después de generar el instalador sin crear un instalador nuevo solamente por ese cambio.

Sin embargo, para la primera configuración se recomienda este orden:

1. Cambiar el nombre del launcher.
2. Vincular el juego.
3. Revisar el tipo de acceso.
4. Generar el launcher.
5. Probar el flujo completo.

De esta forma, la primera prueba queda completa y se reducen los errores de configuración.

## 5. Abre Generate executable

Regresa a la vista general del launcher y selecciona **Generate executable**.

Launcher Forge ofrece dos formatos.

<Frame caption="Selecciona el formato del launcher">
  <img
    src="/images/screenshots/launcher-generation-options.png"
    alt="Página de generación con Windows installer y Portable ZIP"
  />
</Frame>

<CardGroup cols={2}>
  <Card title="Windows installer" icon="windows">
    Genera un instalador oficial para Windows con instalación, accesos directos y desinstalador.

    Es la opción recomendada para la mayoría de los jugadores.
  </Card>

  <Card title="Portable ZIP" icon="file-zipper">
    Genera una carpeta portable comprimida.

    Es útil para distribuir todos los archivos juntos sin utilizar un instalador.
  </Card>
</CardGroup>

Launcher Forge conserva un máximo de un archivo generado por cada formato.

Para crear otro posteriormente, primero debes eliminar el archivo actual.

<Info>
  La base del launcher y su configuración en runtime pueden actualizarse automáticamente. No necesitas regenerar el launcher por cada build, juego vinculado, cambio visual o actualización de contenido.
</Info>

## 6. Genera el archivo

Selecciona **Generate EXE** o **Generate ZIP**, según el formato que prefieras.

Launcher Forge mostrará una ventana de confirmación.

Para generar el instalador de Windows, selecciona **Generate file**.

<Frame caption="Confirma la generación del instalador de Windows">
  <img
    src="/images/screenshots/launcher-generate-confirmation.png"
    alt="Ventana de confirmación para generar el instalador de Windows"
  />
</Frame>

El archivo generado utiliza la información de la configuración del launcher:

- Nombre del launcher.
- Versión técnica.
- Canal.
- Icono del instalador, cuando el plan lo permite.
- Identidad actual del launcher.

<Note>
  El instalador generado conserva el nombre y el icono disponibles en el momento en que fue creado.
</Note>

## 7. Descarga el launcher generado

Espera hasta que el estado cambie a **Ready**.

El panel muestra:

- Nombre del archivo.
- Tamaño.
- Fecha de generación.
- Hash SHA-256.
- Botón de descarga.
- Logs.
- Acción para eliminar.

Selecciona **Download**.

<Frame caption="Descarga el instalador de Windows generado">
  <img
    src="/images/screenshots/launcher-generated-installer.png"
    alt="Instalador generado con acciones Download, Logs y Delete"
  />
</Frame>

Ahora puedes:

- Enviarlo directamente a testers.
- Subirlo a tu página web oficial.
- Publicarlo en una página de descargas.
- Guardarlo dentro de tu sistema de distribución.

<Warning>
  Si cambias el nombre del launcher o necesitas que el instalador de Windows utilice otro icono incrustado, elimina el instalador actual y genera uno nuevo.
</Warning>

<Info>
  Cambiar el icono del launcher en runtime no requiere regenerar el instalador para que las instalaciones existentes reciban la actualización. Solamente permanece sin cambios el icono incrustado dentro del archivo instalador.
</Info>

## 8. Instala y abre el launcher

Ejecuta el instalador descargado y completa la instalación normal de Windows.

Después abre el launcher.

El launcher requiere una **cuenta de usuario final**. Las cuentas del dashboard de desarrollador y las cuentas de usuarios del launcher son distintas.

El jugador debe:

1. Registrar una cuenta de usuario final o iniciar sesión.
2. Completar la verificación de correo cuando sea requerida.
3. Acceder a la biblioteca.

<Info>
  La autenticación de usuarios finales protege el acceso a la biblioteca y permite administrar propiedad, descargas, keys y validación mediante launch tokens.
</Info>

## 9. Adquiere o canjea el juego

La experiencia depende del tipo de acceso seleccionado al vincularlo.

### Juego gratuito

Cuando **Key** estaba desactivado, el launcher muestra la acción **Acquire**.

El jugador selecciona **Acquire** para añadir el juego gratuito a su cuenta.

<Frame caption="Adquiere un juego gratuito desde el launcher">
  <img
    src="/images/screenshots/enduser-launcher-acquire.png"
    alt="Launcher de usuario final mostrando Acquire para un juego gratuito"
  />
</Frame>

Después de adquirirlo, el juego pasa a formar parte de la biblioteca de la cuenta del usuario final.

### Juego protegido mediante key

Cuando **Key** estaba activado:

1. El jugador inicia sesión.
2. El launcher solicita una CD key válida.
3. El jugador ingresa y canjea la key.
4. Launcher Forge valida la key.
5. El juego se añade a la cuenta.
6. El jugador puede instalarlo.

<Warning>
  Un juego protegido no queda desbloqueado solamente por aparecer en el launcher. El usuario final debe canjear una key válida y activa.
</Warning>

## 10. Descarga e instala el juego

Después de adquirirlo o canjearlo, inicia la descarga.

El launcher muestra:

- Estado actual.
- Porcentaje de instalación.
- Tamaño descargado.
- Velocidad.
- Tiempo restante estimado.

<Frame caption="Verifica el progreso de descarga e instalación">
  <img
    src="/images/screenshots/enduser-launcher-downloading.png"
    alt="Launcher de usuario final descargando e instalando el juego"
  />
</Frame>

Espera hasta que el estado del juego cambie a **Ready**.

Luego inicia el juego desde el launcher.

## 11. Verifica el flujo completo

Prueba:

- Registro del usuario final.
- Inicio de sesión.
- Verificación de correo, cuando corresponda.
- Aparición del juego en el launcher.
- Adquisición de un juego gratuito.
- Solicitud de CD key en un juego protegido.
- Canje de una key válida.
- Rechazo de una key inválida, vencida o revocada.
- Descarga correcta.
- Instalación correcta.
- Inicio mediante el ejecutable seleccionado.
- Detección de una nueva versión publicada.
- Actualización correcta del juego.
- Actualización correcta del icono del launcher mediante runtime.
- Mensajes de error comprensibles.

<Check>
  El launcher está listo para distribuirse cuando todo el flujo del jugador funciona correctamente.
</Check>

## Administrar el setup generado

Regresa a **Generate executable** cuando necesites:

- Descargar nuevamente el instalador.
- Revisar los logs de generación.
- Eliminar el EXE actual.
- Eliminar el ZIP actual.
- Generar un reemplazo después de cambiar el nombre del launcher.
- Generar un nuevo instalador con otro icono incrustado.

Eliminar un setup generado no elimina:

- El launcher.
- Los juegos vinculados.
- Las builds.
- Las versiones publicadas.
- Las cuentas de usuarios finales.
- Las CD keys.
- Los registros de propiedad de los jugadores.
