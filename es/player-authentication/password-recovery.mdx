# Recuperación de contraseña

Launcher Forge tiene dos flujos de recuperación diferentes:

<CardGroup cols={2}>
  <Card title="Cuenta de jugador del launcher" icon="gamepad">
    Utiliza un código OTP temporal enviado por correo.
  </Card>

  <Card title="Cuenta del panel de desarrollador" icon="user-gear">
    Utiliza un enlace de recuperación con un token temporal.
  </Card>
</CardGroup>

## Cuenta de jugador del launcher

Los jugadores recuperan su contraseña directamente desde el launcher.

<Steps>
  <Step title="Solicita un código">
    Ingresa el correo registrado en el launcher y selecciona **Send code**.
  </Step>

  <Step title="Revisa el correo">
    Launcher Forge envía un código OTP temporal.
  </Step>

  <Step title="Ingresa el código y la nueva contraseña">
    Escribe el código recibido, define la nueva contraseña y selecciona **Reset password**.
  </Step>

  <Step title="Vuelve al inicio de sesión">
    Después de actualizarla, Launcher Forge envía un correo de confirmación y el jugador puede iniciar sesión con la nueva contraseña.
  </Step>
</Steps>

  El código OTP es temporal. Solicita uno nuevo cuando el anterior haya expirado.
</Warning>

## Cuenta del panel de desarrollador

Las cuentas de desarrollador utilizan otro proceso.

<Steps>
  <Step title="Solicita las instrucciones">
    Ingresa el correo de la cuenta de desarrollador y selecciona **Send instructions**.
  </Step>

  <Step title="Abre el correo de recuperación">
    Launcher Forge envía un enlace que contiene un token temporal.
  </Step>

  <Step title="Define una nueva contraseña">
    Abre el enlace, ingresa y confirma la nueva contraseña, y guarda los cambios.
  </Step>

  <Step title="Inicia sesión nuevamente">
    Después de actualizarla, Launcher Forge envía un correo de confirmación.
  </Step>
</Steps>
