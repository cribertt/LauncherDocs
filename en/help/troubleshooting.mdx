# Troubleshooting

## The launcher does not start

Confirm compatibility, installation, logs, and security software behavior.

## The game does not appear

Verify the workspace, launcher, saved game, visibility, branch access, and account.

## Download or update fails

Check the network, workspace limits, disk space, and active downloads.

## The game installs but does not start

Verify the executable path, dependencies, startup arguments, and logs.

## The CLI cannot publish

Reauthenticate, check permissions, select a packaged folder, use a new version, and review storage limits.

## The launch token is invalid

Start from Launcher Forge, confirm `--launchToken`, review environment and expiration, and keep the Unreal Engine startup delay.
