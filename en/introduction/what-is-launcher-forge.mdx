# What is Launcher Forge?

Launcher Forge helps game developers create branded launchers, publish games, distribute updates, and authenticate players without building the complete delivery system from scratch.

## Main capabilities

<CardGroup cols={2}>
  <Card title="Custom launchers" icon="rocket">Configure templates, branding, navigation, news, and patch notes.</Card>
  <Card title="Game distribution" icon="download">Publish packaged games and deliver them through a desktop launcher.</Card>
  <Card title="Build management" icon="boxes-stacked">Organize branches, versions, patches, hotfixes, and manifests.</Card>
  <Card title="Player authentication" icon="shield-halved">Validate players who start a game from Launcher Forge.</Card>
  <Card title="Engine integrations" icon="gamepad">Connect supported Unreal Engine and Unity projects.</Card>
  <Card title="Workspace controls" icon="gauge-high">Manage plans, usage, storage, bandwidth, members, and permissions.</Card>
</CardGroup>
