# CLI authentication

Authentication is handled through the CLI menus and prompts.

The interactive menu can provide options such as:

```text
Launcher Forge CLI

❯ Upload a build
  View upload status
  List versions
  Manage permissions
  Sign out
  Show CLI version
```

OAuth-created accounts may need to create a Launcher Forge password before using a credential-based CLI login.
