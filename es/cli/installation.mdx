# Instalar la CLI

La CLI utiliza menús guiados y no requiere comandos largos.

<Steps>
  <Step title="Descarga la CLI oficial">Utiliza la descarga de Launcher Forge.</Step>
  <Step title="Extrae el paquete">Descomprime cuando sea necesario.</Step>
  <Step title="Abre una terminal">Usa PowerShell, Windows Terminal u otra terminal compatible.</Step>
  <Step title="Ejecuta la aplicación">Inicia la CLI.</Step>
  <Step title="Autentícate">Completa el inicio de sesión interactivo.</Step>
</Steps>
