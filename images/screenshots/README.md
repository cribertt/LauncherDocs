# Reemplazar capturas

Los PNG de esta carpeta son marcadores de posición.

Para agregar tus fotos o capturas reales:

1. Captura la pantalla de Launcher Forge.
2. Oculta correos, tokens, API keys, URLs privadas y datos personales.
3. Exporta como PNG.
4. Reemplaza el archivo conservando exactamente el mismo nombre.
5. No necesitas modificar el MDX.
6. Mantén una proporción cercana a 16:9.
7. Revisa la documentación en modo claro y oscuro.

Cada página ya contiene un componente `<Frame>` con caption.
