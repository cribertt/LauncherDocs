# Actualizaciones

1. Se escanea la build.
2. Se calcula SHA-256 por archivo.
3. Se crea un manifiesto.
4. Se detectan archivos nuevos o modificados.
5. El launcher descarga lo necesario para la versión.

<Info>
  Renombrar o recompilar un archivo puede cambiar su hash.
</Info>
