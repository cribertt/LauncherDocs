# Branches

| Branch | Purpose |
| --- | --- |
| **Stable** | Production-ready releases. |
| **Beta** | Limited or public pre-release testing. |
| **Alpha** | Early feature validation. |
| **Development** | Internal development and QA. |

Branches can be public or private when supported by the workspace plan.
