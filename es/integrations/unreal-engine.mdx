# Integración con Unreal Engine

<Steps>
  <Step title="Instala el plugin">Añade el plugin a una versión compatible.</Step>
  <Step title="Activa el plugin">Reinicia el editor cuando corresponda.</Step>
  <Step title="Configura Game Instance">Inicializa la autenticación durante el arranque.</Step>
  <Step title="Espera antes de validar">Mantén el delay recomendado de `0.5` segundos.</Step>
