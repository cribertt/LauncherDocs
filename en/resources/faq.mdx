# Frequently asked questions

<AccordionGroup>
  <Accordion title="Is the CLI command-based?">No. Launcher Forge uses an interactive CLI with guided menus.</Accordion>
  <Accordion title="How are updates detected?">Launcher Forge uses manifests and SHA-256 hashes to identify changed files.</Accordion>
  <Accordion title="What are STABLE, PATCH, and HOTFIX?">They describe a complete baseline, a planned update, and an urgent correction.</Accordion>
  <Accordion title="Can a branch be private?">Private branches depend on the plan and permissions.</Accordion>
  <Accordion title="Why can a game install but fail to start?">Common causes include an incorrect executable path, missing runtime dependencies, or launch settings.</Accordion>
  <Accordion title="Where can I review storage and bandwidth?">Use the workspace usage and billing areas.</Accordion>
</AccordionGroup>
