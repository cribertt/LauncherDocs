# Añadir tu primer juego

Un juego representa el producto que tus jugadores podrán instalar, actualizar y ejecutar mediante Launcher Forge.

Los juegos se crean desde la sección **Catalog** o **Catálogo** del dashboard de desarrollador.

<Info>
  Actualmente, tu cuenta utiliza un único workspace y un único launcher. Cada juego creado pertenece a ese workspace y posteriormente puede vincularse con el launcher existente.
</Info>

## Antes de comenzar

Antes de crear el juego, prepara:

- El nombre definitivo del juego.
- Una descripción breve.
- El género.
- Una imagen de portada.
- Un banner o imagen de fondo, cuando corresponda.
- El nombre esperado del ejecutable.
- Una build empaquetada que funcione correctamente en tu equipo.

No necesitas subir la build durante este paso. Las builds se publican posteriormente mediante la CLI interactiva de Launcher Forge.

## 1. Abre el Catálogo

Inicia sesión en el dashboard de Launcher Forge.

En el menú lateral izquierdo, busca la sección **MY GAMES** y selecciona **Catalog**.

El Catálogo contiene todos los juegos registrados en tu workspace.

## 3. Completa la información del juego

Ingresa la información solicitada por el formulario.

### Nombre del juego

Ingresa el nombre público del juego.

Utiliza el nombre definitivo que debería mostrarse en:

- La biblioteca del launcher.
- Las tarjetas del juego.
- Las páginas de releases.
- Las pantallas visibles para jugadores.

### Slug

El slug es el identificador estable utilizado por Launcher Forge en URLs y referencias internas.

Utiliza letras minúsculas, números y guiones.

Por ejemplo:

```text
mi-primer-juego
```

<Warning>
  Evita cambiar el slug después de publicar builds o compartir enlaces relacionados con el juego.
</Warning>

### Descripción

Escribe un resumen claro que explique de qué trata el juego.

Debe ser comprensible para los jugadores y no debería contener notas internas de desarrollo.

### Género

Selecciona el género que mejor represente al juego.

Esta información puede utilizarse para organizar y mostrar el juego dentro del launcher.

## 5. Crea el juego

Revisa la información ingresada y envía el formulario.

Después de crearlo, Launcher Forge abrirá su página de administración o lo añadirá al Catálogo.

El juego debería aparecer como un producto registrado dentro del workspace.

<Check>
  El juego fue creado correctamente, pero todavía no contiene una build publicada.
</Check>

## 6. Configura el ejecutable

La configuración del ejecutable le indica a Launcher Forge qué archivo debe iniciar después de instalar el juego.

Utiliza una ruta relativa a la raíz de la build empaquetada.

Por ejemplo:

```text
MiJuego.exe
```

Si el ejecutable se encuentra dentro de una carpeta:

```text
Binaries/Win64/MiJuego.exe
```

No utilices una ruta absoluta de tu equipo:

```text
C:\Users\Desarrollador\Desktop\MiJuego\MiJuego.exe
```

Esa ruta existe solamente en tu computador y no funcionará para los jugadores.

## 7. Revisa la página del juego

Después de crear el juego, revisa su información principal:

- Nombre.
- Slug.
- Descripción.
- Género.
- Portada y banner.
- Ruta del ejecutable.
- Configuración de instalación.
- Ramas existentes.
- Versiones publicadas.

En este punto, el juego existe dentro del Catálogo, pero todavía necesita una rama y al menos una build publicada.

## 8. Vincula el juego con el launcher

Abre tu launcher desde el menú lateral e ingresa a la sección **Linked games**.

Selecciona el juego que acabas de crear y asócialo con el launcher.

Después de vincularlo, la página de administración del launcher ya no debería mostrar `0` juegos vinculados.

## ¿Qué debes hacer después?

Después de crear y vincular el juego:

<Steps>
  <Step title="Revisa el ejecutable">
    Confirma que la ruta coincida con la estructura real de la build empaquetada.
  </Step>

  <Step title="Crea o selecciona una rama">
    Utiliza el canal correspondiente, como stable, beta o development.
  </Step>

  <Step title="Prepara la build empaquetada">
    Empaqueta el juego y pruébalo localmente.
  </Step>

  <Step title="Publica la build">
    Utiliza la CLI interactiva para analizar y subir los archivos.
  </Step>

  <Step title="Prueba el launcher">
    Instala y ejecuta el juego desde el launcher generado.
  </Step>
</Steps>

<Warning>
  No generes ni distribuyas el launcher definitivo sin confirmar que el juego está vinculado y tiene una build válida publicada.
</Warning>
