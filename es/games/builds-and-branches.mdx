# Builds y ramas

| Rama | Uso habitual |
| --- | --- |
| **Stable** | Producción. |
| **Beta** | Pruebas públicas o limitadas. |
| **Alpha** | Validación temprana. |
| **Development** | Desarrollo interno o QA. |
| **Private** | Distribución restringida según el plan. |
