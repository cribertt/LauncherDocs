# Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿La CLI utiliza comandos?">No. La CLI es interactiva y utiliza menús.</Accordion>
  <Accordion title="¿Qué diferencia existe entre STABLE, PATCH y HOTFIX?">STABLE es una base completa, PATCH una actualización planificada y HOTFIX una corrección urgente.</Accordion>
  <Accordion title="¿Cómo se detectan las actualizaciones?">Se calculan hashes SHA-256 y se crea un manifiesto.</Accordion>
  <Accordion title="¿Puedo crear ramas privadas?">Depende del plan y de los permisos.</Accordion>
  <Accordion title="¿Por qué se instala el juego, pero no inicia?">Revisa la ruta del ejecutable, dependencias y configuración.</Accordion>
  <Accordion title="¿Launcher Forge es compatible con Unreal Engine?">La documentación inicial incluye autenticación mediante launch token.</Accordion>
  <Accordion title="¿Dónde están Unity, Godot, API, DLC, commerce, webhooks e IA?">Se publicarán cuando estén disponibles, en beta, experimentales o próximos a lanzarse.</Accordion>
  <Accordion title="¿Dónde reviso almacenamiento y ancho de banda?">En las áreas de uso y facturación.</Accordion>
</AccordionGroup>
