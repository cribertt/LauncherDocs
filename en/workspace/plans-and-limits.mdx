# Plans and limits

Plan limits can include:

- Launchers.
- Games.
- Members.
- Storage.
- Bandwidth.
- Branches.
- Templates.
- Analytics.
- API access.

The dashboard is the current source of truth for the active workspace plan and available entitlements.
