# Publish your first build

Launcher Forge uses an **interactive CLI**. You do not need to construct a deployment command with flags.

<Steps>
  <Step title="Open the CLI">Start the official Launcher Forge CLI executable.</Step>
  <Step title="Authenticate">Complete the guided login when required.</Step>
  <Step title="Select Upload a build">Choose the publishing option from the menu.</Step>
  <Step title="Complete the prompts">Select game, branch, version, release type, build directory, and changelog.</Step>
  <Step title="Confirm">Review the summary before the upload starts.</Step>
</Steps>
