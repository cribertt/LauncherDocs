# Solución de problemas

Incluye:

- El launcher no inicia.
- No se puede iniciar sesión.
- El juego no aparece.
- La descarga falla.
- El juego no se actualiza.
- El juego no inicia.
- La CLI no publica.
- El token no es válido.

Recopila error exacto, cuenta, juego, rama, versión, sistema operativo y logs.
