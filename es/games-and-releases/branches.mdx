# Ramas

| Rama | Propósito |
| --- | --- |
| **Stable** | Producción. |
| **Beta** | Pruebas previas públicas o limitadas. |
| **Alpha** | Validación temprana. |
| **Development** | Desarrollo interno y QA. |

Las ramas pueden ser públicas o privadas según el plan.
