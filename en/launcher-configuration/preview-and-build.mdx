# Preview and build

Use the preview before saving or generating the launcher.

## Review

- Layout.
- Text.
- Images and video.
- Navigation.
- News and patch notes.
- Login and registration states.
- Empty states.
- Maintenance state.

After review, save the configuration and use the available launcher generation workflow.
