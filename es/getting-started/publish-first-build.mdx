# Publicar tu primera build

Launcher Forge publica las builds mediante una **CLI interactiva**.

No necesitas crear un comando largo de despliegue ni memorizar parámetros. La CLI te guía durante todo el proceso mediante menús y preguntas.

<Warning>
  Publicar el juego dentro del Catálogo solamente hace visible su ficha dentro del launcher. No sube los archivos del juego. Debes publicar al menos una build mediante la CLI para que los jugadores puedan instalarlo y ejecutarlo.
</Warning>

## Antes de comenzar

Confirma lo siguiente:

- El juego existe dentro del Catálogo.
- Su estado es **Published**.
- Tiene al menos una rama.
- El acceso mediante CLI está habilitado.
- Tienes una build empaquetada que funciona correctamente.
- Conoces el ejecutable utilizado para iniciar el juego.
- El workspace tiene almacenamiento disponible.
- Tu cuenta tiene permisos para publicar builds.

<Note>
  Las cuentas creadas mediante Google o GitHub pueden necesitar establecer una contraseña de Launcher Forge antes de iniciar sesión en la CLI mediante correo y contraseña.
</Note>

## 1. Abre la sección CLI

Inicia sesión en el dashboard de Launcher Forge.

En el menú lateral izquierdo, selecciona **CLI**.

Launcher Forge mostrará los juegos disponibles para publicar mediante la CLI.

Selecciona el juego que quieres publicar. Puedes presionar su tarjeta o utilizar **Open CLI**.

## 2. Revisa la página CLI del juego

La página específica del juego muestra la información utilizada por el flujo de publicación.

Revisa:

- **Application ID**.
- Cantidad de ramas.
- Rama predeterminada.
- Estado del acceso mediante CLI.
- Versión del instalador.
- Tamaño del archivo.

El Application ID identifica internamente al juego. Después de iniciar sesión, la CLI obtiene los juegos disponibles, por lo que normalmente seleccionas el juego desde el menú y no necesitas escribir este ID manualmente.

## 3. Descarga la CLI

Selecciona **Download CLI**.

La descarga utiliza tu sesión activa del dashboard y valida el estado de la contraseña de la cuenta.

Guarda el instalador de Windows en tu equipo.

<Warning>
  Descarga la CLI solamente desde el dashboard oficial de Launcher Forge. No ejecutes copias recibidas desde fuentes desconocidas.
</Warning>

2. La rama de destino.

- `main`
- `stable`

## 8. Define la release

La CLI solicitará la información de la release.

### Versión

Ingresa un número de versión nuevo.

Se recomienda un formato semántico:

```text
MAJOR.MINOR.PATCH
```

Ejemplos:

```text
1.0.0
1.1.0
1.1.1
```

No reutilices una versión que ya exista para el juego y la rama seleccionados.

### Tipo de publicación

Selecciona uno de los tipos disponibles.

<Tabs>
  <Tab title="STABLE">
    Utiliza `STABLE` para establecer una base completa de publicación.

    Launcher Forge procesa la build empaquetada completa.
  </Tab>

  <Tab title="PATCH">
    Utiliza `PATCH` para una actualización planificada.

    Launcher Forge compara el nuevo manifiesto con los hashes existentes y sube los archivos requeridos por la nueva versión.
  </Tab>

  <Tab title="HOTFIX">
    Utiliza `HOTFIX` para una corrección urgente y específica.

    Utiliza la comparación de manifiestos, pero deja claramente indicada la intención urgente de la publicación.
  </Tab>
</Tabs>

### Changelog

Escribe un resumen breve y comprensible para los jugadores.

Ejemplo:

```text
Se añadió reasignación de controles, se mejoraron los tiempos de carga y se corrigió un cierre inesperado al cambiar de región.
```

No incluyas contraseñas, tokens, URLs privadas ni información interna de infraestructura.

## 9. Selecciona la build empaquetada

Selecciona la carpeta local que contiene los archivos compilados y empaquetados.

Por ejemplo:

```text
MiJuegoBuild/
├── MiJuego.exe
├── Content/
├── Engine/
└── Config/
```

Selecciona la raíz de la build empaquetada, no la carpeta del proyecto de Unreal Engine o Unity.

No selecciones carpetas con:

- Código fuente.
- Caché del editor.
- Archivos intermedios.
- Contenido temporal.
- Credenciales.
- Configuración privada.

## 10. Analiza y publica

Antes de comenzar, la CLI mostrará un resumen de los valores seleccionados.

Revisa:

- Juego.
- Rama.
- Versión.
- Tipo.
- Changelog.
- Directorio de la build.

Confirma solamente cuando todo sea correcto.

Luego Launcher Forge:

1. Escanea los archivos.
2. Calcula hashes SHA-256.
3. Genera el manifiesto.
4. Detecta los archivos que deben subirse.
5. Sube los artefactos requeridos.
6. Crea la nueva versión.

## Si la carga falla

La CLI debería mostrar la causa y devolverte a un menú utilizable en lugar de cerrarse inesperadamente.

Algunas causas frecuentes son:

- Sesión inválida o vencida.
- Permisos insuficientes.
- Versión duplicada.
- Carpeta empaquetada inválida.
- Límite de almacenamiento.
- Interrupción de red.
- Ejecutable inexistente.
- Archivos modificados durante la subida.

Corrige la causa indicada antes de volver a intentarlo.
