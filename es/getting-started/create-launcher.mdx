# Crear tu primer launcher

<Steps>
  <Step title="Abre Launchers">Ingresa al área de Launchers.</Step>
  <Step title="Crea el launcher">Ingresa un nombre y slug estable.</Step>
  <Step title="Selecciona un template">Elige uno disponible para el plan.</Step>
  <Step title="Selecciona el idioma">Define el idioma predeterminado.</Step>
  <Step title="Guarda">Crea el launcher antes de añadir contenido detallado.</Step>
</Steps>
