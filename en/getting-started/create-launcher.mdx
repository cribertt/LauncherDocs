# Create your first launcher

<Steps>
  <Step title="Open Launchers">Open the Launchers area in the dashboard.</Step>
  <Step title="Create a launcher">Enter the name and stable unique slug.</Step>
  <Step title="Choose a template">Select a template available to the active plan.</Step>
  <Step title="Choose the language">Set the default launcher language.</Step>
  <Step title="Save">Create the launcher before adding detailed content.</Step>
</Steps>
