# Test your launcher

Test the complete player experience before a public release.

## Verification checklist

- Download and install the launcher.
- Sign in with a test player account.
- Confirm the game appears in the library.
- Install the game.
- Start the game.
- Confirm launch-token validation.
- Publish an update and verify the update flow.
- Review errors and recovery behavior.
