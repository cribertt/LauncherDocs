# Añadir tu primer juego

Los juegos se crean y administran desde la sección **Catalog** o **Catálogo** del dashboard de Launcher Forge.

Como actualmente cada cuenta utiliza un único workspace y un único launcher, todos los juegos creados en el Catálogo pertenecen a ese workspace y pueden mostrarse en el launcher existente después de publicarlos.

<Warning>
  Cada juego nuevo se crea como **Draft** o **Borrador** de manera predeterminada. Un borrador no es público y no aparece en el launcher para los jugadores.
</Warning>

Para que el juego sea visible, primero debes crearlo, abrir su editor, cambiar su estado de publicación a **Published** y guardar los cambios.

## Antes de comenzar

Prepara la siguiente información:

- El nombre público del juego.
- Una descripción.
- Uno o más géneros.
- Una imagen de portada.
- Una build empaquetada para un paso posterior.

La build no se sube durante la creación del juego. Las builds se publican por separado mediante la CLI interactiva de Launcher Forge.

## 1. Abre el Catálogo

Inicia sesión en el dashboard de Launcher Forge.

En el menú lateral izquierdo, busca **MY GAMES** y selecciona **Catalog**.

El Catálogo muestra:

- Total de juegos.
- Juegos publicados.
- Borradores.
- Juegos archivados.
- Buscador y filtros por estado.

Selecciona **New Game** en la esquina superior derecha.

## 2. Completa la información inicial del juego

Launcher Forge abrirá la página **Create new game**.

El juego será creado como borrador, tal como indica el mensaje:

```text
It will be created as a draft
```

Completa los campos disponibles.

### Nombre del juego

Ingresa el nombre público que los jugadores verán en el launcher.

Utiliza un nombre definitivo y fácil de reconocer. Podrás modificarlo más adelante.

### Descripción

Describe el universo, las mecánicas o la propuesta principal del juego.

El formulario permite hasta `500` caracteres para esta descripción inicial.

### Géneros

Selecciona los géneros que mejor representen al juego.

Algunos ejemplos disponibles son:

- RPG.
- Action.
- Adventure.
- Strategy.
- Puzzle.
- Simulation.
- Sports.
- Horror.
- Indie.

### Portada del juego

La portada es opcional durante la creación inicial, pero es recomendable añadirla.

La interfaz acepta:

- PNG.
- JPG.
- WEBP.
- GIF.

El tamaño máximo indicado por el formulario es de `10 MB`.

Launcher Forge recomienda una imagen de `1920 × 1080` para obtener una mejor visualización dentro del launcher.

<Note>
  El nombre del juego y al menos un género son obligatorios. La portada es opcional, pero mejora la presentación dentro del launcher.
</Note>

## 3. Crea el juego

Después de completar los campos obligatorios, envía el formulario.

Launcher Forge creará el juego y lo mostrará en el Catálogo.

El juego recién creado aparecerá con el estado **Draft**.

<Info>
  Draft significa que el juego existe dentro de tu workspace, pero solamente tú puedes verlo en el dashboard de desarrollador. Los jugadores todavía no pueden verlo en el launcher.
</Info>

## 4. Abre el editor del juego

Busca la tarjeta del juego dentro del Catálogo.

Pasa el cursor sobre la tarjeta y selecciona el icono de lápiz identificado como **Edit game**.

<Frame caption="Abre el juego en borrador mediante Edit game">
  <img
    src="/images/screenshots/draft-game-edit.png"
    alt="Tarjeta de un juego en borrador con el botón Edit game destacado"
  />
</Frame>

El editor permite revisar y modificar la información antes de publicar el juego.

## 5. Abre la pestaña Publishing

Dentro del editor del juego, selecciona la pestaña **Publishing**.

<Frame caption="Abre la pestaña Publishing dentro del editor">
  <img
    src="/images/screenshots/game-publishing-tab.png"
    alt="Editor de juego de Launcher Forge con la pestaña Publishing destacada"
  />
</Frame>

La pestaña Publishing ofrece tres estados:

| Estado | Comportamiento |
| --- | --- |
| **Published** | Visible en el launcher para todos los usuarios con acceso. |
| **Draft** | Visible solamente para ti en el dashboard de desarrollador. |
| **Archived** | Oculto del launcher. |

## 6. Publica el juego

Selecciona **Published**.

Luego selecciona **Save changes**.

<Frame caption="Selecciona Published y guarda los cambios">
  <img
    src="/images/screenshots/publish-game-save.png"
    alt="Pestaña Publishing con Published y Save changes destacados"
  />
</Frame>

Después de guardar:

- El juego dejará de ser un borrador.
- Aparecerá dentro del filtro **Published**.
- Aumentará el contador de juegos publicados.
- Será visible dentro del launcher.

<Warning>
  Seleccionar Published no es suficiente por sí solo. También debes presionar **Save changes** o el nuevo estado no será aplicado.
</Warning>

## Draft, Published y Archived

<Tabs>
  <Tab title="Draft">
    Utiliza Draft mientras la información esté incompleta o mientras preparas sus imágenes, configuración, ramas y primera build.

    Los juegos en Draft no son visibles para los jugadores.
  </Tab>

  <Tab title="Published">
    Utiliza Published cuando el juego esté listo para aparecer dentro del launcher.

    Publicar el juego hace visible su ficha, pero no sube automáticamente una build.
  </Tab>

  <Tab title="Archived">
    Utiliza Archived cuando el juego ya no deba aparecer en el launcher.

    Archivar no significa eliminar el juego.
  </Tab>
</Tabs>

## Importante: publicar el juego no es lo mismo que publicar una build

Cambiar el estado del juego a **Published** controla su visibilidad dentro del launcher.

No realiza automáticamente las siguientes acciones:

- Subir los archivos del juego.
- Crear una rama.
- Crear una versión.
- Publicar una build estable, patch o hotfix.
- Configurar el ejecutable.

Las builds se publican por separado mediante la CLI interactiva de Launcher Forge.

## Verificación final

Antes de continuar, comprueba:

- El juego aparece en el Catálogo.
- Su estado es **Published**.
- La información es correcta.
- Tiene al menos un género seleccionado.
- La portada se muestra correctamente.
- El juego aparece dentro del launcher.
- Estás listo para configurar ramas y publicar una build.

<Check>
  Tu juego fue creado y publicado correctamente. Ahora es visible dentro del launcher, pero todavía necesita una build válida para que los jugadores puedan instalarlo y ejecutarlo.
</Check>
