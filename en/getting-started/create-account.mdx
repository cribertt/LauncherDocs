# Create your account

<Steps>
  <Step title="Register">Create the developer account using the available registration method.</Step>
  <Step title="Verify the account">Complete any required email verification.</Step>
  <Step title="Sign in">Open the Launcher Forge dashboard.</Step>
  <Step title="Create the workspace">Enter the workspace name and confirm the initial owner.</Step>
</Steps>
