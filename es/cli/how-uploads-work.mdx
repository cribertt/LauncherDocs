# Cómo funcionan las cargas

1. Escaneo.
2. Cálculo SHA-256.
3. Manifiesto.
4. Detección de cambios.
5. Subida de archivos.
6. Creación de la versión.

- `STABLE` establece una base completa.
- `PATCH` y `HOTFIX` utilizan comparación de manifiestos.
