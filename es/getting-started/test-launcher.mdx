# Probar tu launcher

## Lista de verificación

- Descarga e instala el launcher.
- Inicia sesión con una cuenta de jugador de prueba.
- Confirma que el juego aparezca en la biblioteca.
- Instala el juego.
- Ejecuta el juego.
- Verifica el launch token.
- Publica una actualización y prueba el flujo.
- Revisa errores y recuperación.
