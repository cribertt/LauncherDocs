# Publicar tu primera build

Launcher Forge utiliza una **CLI interactiva**. No necesitas construir un comando de despliegue con flags.

<Steps>
  <Step title="Abre la CLI">Ejecuta la aplicación oficial.</Step>
  <Step title="Autentícate">Completa el login guiado.</Step>
  <Step title="Selecciona Subir una build">Elige la opción desde el menú.</Step>
  <Step title="Completa los pasos">Selecciona juego, rama, versión, tipo, carpeta y changelog.</Step>
  <Step title="Confirma">Revisa el resumen antes de comenzar.</Step>
</Steps>
