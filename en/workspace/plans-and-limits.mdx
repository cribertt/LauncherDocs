# Plans and limits

Common plan limits include:

- Launchers.
- Games.
- Team members.
- Storage.
- Bandwidth.
- Branches.
- Templates.
- Analytics.
- API access.

## Storage

Storage measures the game and build content retained by Launcher Forge.

## Bandwidth

Bandwidth measures data transferred when players download or update content.

## When a limit is reached

Launcher Forge may block resource creation, build uploads, private branches, templates, members, or plan-specific features.

<Note>
  The dashboard is the current source of truth for the active plan and usage.
</Note>
