# Preview y generación

Revisa:

- Layout.
- Textos.
- Imágenes y video.
- Navegación.
- Noticias y patch notes.
- Login y registro.
- Estados vacíos.
- Mantenimiento.

Después guarda la configuración y utiliza el flujo de generación disponible.
