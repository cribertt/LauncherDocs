# Añadir tu primer juego

Los juegos se crean y administran desde la sección **Catalog** o **Catálogo** del dashboard de Launcher Forge.

Actualmente, cada cuenta de Launcher Forge utiliza un único workspace y un único launcher. Todos los juegos creados en el Catálogo pertenecen a ese workspace y posteriormente pueden conectarse con el launcher existente.

<Note>
  Los juegos nuevos se crean como **Draft** o **Borrador** de manera predeterminada.

  El borrador permanece dentro del dashboard hasta que cambies su estado a **Published** y guardes los cambios.
</Note>

## Cómo funciona el proceso completo

Crear un juego dentro del Catálogo es solamente la primera parte del proceso de distribución.

```text
Crear el juego en el Catálogo
        ↓
Publicar la ficha del juego
        ↓
Configurar la validación launcher-juego
        ↓
Publicar la build empaquetada
        ↓
Vincular el juego con el launcher
        ↓
Generar y probar el launcher
```

Estas son partes separadas del sistema:

- La **ficha del Catálogo** contiene la información del juego.
- La **validación launcher-juego** establece la conexión técnica confiable entre el launcher y el runtime.
- La **build publicada** contiene los archivos empaquetados.
- La **vinculación** hace que el juego forme parte del launcher.

## Antes de comenzar

Prepara la siguiente información:

- El nombre público del juego.
- Una descripción.
- Uno o más géneros.
- Una imagen de portada.
- Una build empaquetada para un paso posterior.
- La integración del motor que utilizarás para la validación launcher-juego.

La build no se sube durante la creación del juego. Las builds se publican posteriormente mediante la CLI interactiva de Launcher Forge.

## 1. Abre el Catálogo

Inicia sesión en el dashboard de Launcher Forge.

En el menú lateral izquierdo, busca **MY GAMES** y selecciona **Catalog**.

El Catálogo muestra:

- Total de juegos.
- Juegos publicados.
- Borradores.
- Juegos archivados.
- Buscador y filtros por estado.

Selecciona **New Game** en la esquina superior derecha.

## 2. Completa la información inicial

Launcher Forge abrirá la página **Create new game**.

La interfaz indica que el juego será creado inicialmente como borrador:

```text
It will be created as a draft
```

Completa los campos disponibles.

### Nombre del juego

Ingresa el nombre público que identificará al juego dentro de Launcher Forge.

El nombre puede aparecer en:

- El Catálogo.
- Las tarjetas del launcher.
- La biblioteca.
- La información de releases.
- La selección del juego dentro de la CLI.

Utiliza un nombre definitivo y fácil de reconocer. Podrás modificarlo más adelante cuando sea necesario.

### Descripción

Describe el universo, las mecánicas, el género o la propuesta principal del juego.

La descripción inicial permite hasta `500` caracteres.

Escribe información destinada a describir el juego. Evita notas internas, credenciales, URLs privadas o información de infraestructura.

### Géneros

Selecciona los géneros que mejor representen al juego.

Algunos ejemplos disponibles son:

- RPG.
- Action.
- Adventure.
- Strategy.
- Puzzle.
- Simulation.
- Sports.
- Horror.
- Indie.

Debes seleccionar al menos un género antes de crear el juego.

### Portada del juego

La portada es opcional durante la creación inicial, pero se recomienda añadirla.

La interfaz acepta:

- PNG.
- JPG.
- WEBP.
- GIF.

El tamaño máximo indicado por el formulario es de `10 MB`.

Launcher Forge recomienda una imagen de `1920 × 1080` para obtener una mejor presentación dentro del launcher.

## 3. Crea el juego

Después de completar los campos obligatorios, envía el formulario.

Launcher Forge creará el juego y lo mostrará en el Catálogo.

El juego recién creado aparecerá con el estado **Draft**.

En este punto:

- El juego existe en el Catálogo.
- Todavía no tiene una build publicada.
- Todavía no está vinculado con el launcher.
- La validación launcher-juego puede no estar configurada.
- No está disponible para distribuirse mediante el launcher.

<Info>
  Draft es un estado de preparación. Permite configurar el juego antes de habilitar su ficha para la distribución.
</Info>

## 4. Abre el editor del juego

Busca la tarjeta del juego dentro del Catálogo.

Pasa el cursor sobre la tarjeta y selecciona el icono de lápiz identificado como **Edit game**.

<Frame caption="Abre el juego en borrador mediante Edit game">
  <img
    src="/images/screenshots/draft-game-edit.png"
    alt="Tarjeta de juego en borrador con el botón Edit game destacado"
  />
</Frame>

El editor permite revisar y modificar el juego antes de publicar su ficha.

## 5. Revisa la información

Dentro del editor, abre la pestaña **Information**.

Confirma:

- Nombre del juego.
- Descripción corta.
- Descripción completa.
- Géneros seleccionados.
- Portada.
- Banner, cuando esté disponible.
- Otros metadatos.

Guarda los cambios antes de continuar.

<Note>
  Publicar controla el estado de la ficha. No sube una build, no conecta el runtime ni vincula el juego con el launcher.
</Note>

## 6. Abre la pestaña Publishing

Dentro del editor, selecciona **Publishing**.

<Frame caption="Abre la pestaña Publishing dentro del editor">
  <img
    src="/images/screenshots/game-publishing-tab.png"
    alt="Editor de juego de Launcher Forge con la pestaña Publishing destacada"
  />
</Frame>

La pestaña Publishing ofrece tres estados:

| Estado | Comportamiento |
| --- | --- |
| **Published** | La ficha queda disponible para la distribución y puede vincularse con el launcher. |
| **Draft** | El juego continúa en preparación dentro del dashboard. |
| **Archived** | El juego queda fuera de la distribución sin ser eliminado. |

## 7. Publica la ficha del juego

Selecciona **Published**.

Luego presiona **Save changes**.

<Frame caption="Selecciona Published y guarda los cambios">
  <img
    src="/images/screenshots/publish-game-save.png"
    alt="Pestaña Publishing con Published y Save changes destacados"
  />
</Frame>

Después de guardar:

- El juego deja de ser un borrador.
- Aparece dentro del filtro **Published**.
- Aumenta el contador de juegos publicados.
- Queda disponible para vincularlo con el launcher.

<Warning>
  Seleccionar **Published** no es suficiente por sí solo. También debes presionar **Save changes** o el nuevo estado no será aplicado.
</Warning>

<Info>
  Publicar la ficha no añade automáticamente el juego a la biblioteca del launcher. Todavía debes vincularlo con el launcher del workspace.
</Info>

## Draft, Published y Archived

<Tabs>
  <Tab title="Draft">
    Utiliza Draft mientras la información esté incompleta o mientras preparas:

    - Imágenes.
    - Descripciones.
    - Validación launcher-juego.
    - Ramas.
    - Builds.
    - Información de releases.

    Los juegos en Draft no están disponibles para distribuirse.
  </Tab>

  <Tab title="Published">
    Utiliza Published cuando la ficha esté lista para participar en el flujo de distribución.

    Publicar permite vincular el juego con el launcher, pero no sube sus archivos empaquetados.
  </Tab>

  <Tab title="Archived">
    Utiliza Archived cuando el juego ya no deba estar disponible para la distribución.

    Archivar no elimina:

    - El juego.
    - Sus ramas.
    - Sus builds.
    - Sus versiones.
    - Sus archivos almacenados.
  </Tab>
</Tabs>

## Publicar el juego no es publicar una build

Cambiar el estado a **Published** solamente controla el estado de la ficha dentro del Catálogo.

No realiza automáticamente las siguientes acciones:

- Subir los archivos empaquetados.
- Generar un manifiesto.
- Crear una versión.
- Publicar una release `STABLE`, `PATCH` o `HOTFIX`.
- Seleccionar el ejecutable principal.
- Configurar la validación launcher-juego.
- Vincular el juego con el launcher.
- Generar el instalador del launcher.

Las builds se publican por separado mediante la CLI interactiva de Launcher Forge.

## Configura la validación launcher-juego

Antes de subir la primera build destinada a la distribución, configura la conexión técnica entre el launcher y el runtime del juego.

Esta validación permite que el launcher de Launcher Forge reconozca y valide el ejecutable que inicia.

```text
Launcher de Launcher Forge
        ↓
Inicia el ejecutable del juego
        ↓
Entrega los datos de validación
        ↓
La integración del juego valida la conexión
        ↓
Inicio launcher-juego confiable
```

Esta conexión es independiente de:

- Registro de usuarios finales.
- Inicio de sesión de usuarios finales.
- Propiedad del juego.
- Canje de CD keys.
- Biblioteca del jugador.

Esas funciones pertenecen a los sistemas de usuario final y acceso al juego. La validación launcher-juego cubre específicamente la conexión entre el launcher y el runtime.

## Verificación final

Antes de continuar, comprueba:

- El juego aparece en el Catálogo.
- Su estado es **Published**.
- La información es correcta.
- Tiene al menos un género.
- La portada se muestra correctamente.
- Está disponible para vincularse.
- Seleccionaste la integración adecuada para el motor.
- La validación launcher-juego está configurada.
- La build empaquetada funciona correctamente en tu equipo.
- Estás listo para crear la primera versión mediante la CLI.

<Check>
  La ficha del juego fue creada y publicada correctamente.
</Check>
