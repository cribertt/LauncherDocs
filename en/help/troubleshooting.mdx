# Troubleshooting

Cover these common problems:

- Launcher does not start.
- Sign-in fails.
- Game does not appear.
- Download fails.
- Game does not update.
- Game does not start.
- CLI cannot publish.
- Launch token is invalid.

Start by collecting the exact error, affected account, game, branch, version, operating system, and relevant logs.
