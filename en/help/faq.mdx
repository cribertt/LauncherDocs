# Frequently asked questions

<AccordionGroup>
  <Accordion title="Is the CLI command-based?">No. It is interactive and uses menus and prompts.</Accordion>
  <Accordion title="What is the difference between STABLE, PATCH, and HOTFIX?">STABLE creates a complete baseline, PATCH is a planned update, and HOTFIX is an urgent correction.</Accordion>
  <Accordion title="How are updates detected?">The CLI scans files, calculates SHA-256 hashes, creates a manifest, and detects changed content.</Accordion>
  <Accordion title="Can I create private branches?">Private branches depend on the active plan and permissions.</Accordion>
  <Accordion title="Why does the game install but not start?">Common causes are the executable path, missing dependencies, or startup settings.</Accordion>
  <Accordion title="Does Launcher Forge support Unreal Engine?">The initial documentation includes Unreal Engine launch-token authentication.</Accordion>
  <Accordion title="Where are Unity, Godot, API, DLC, commerce, webhooks, and AI?">Publish these sections only when the corresponding functionality is available, beta, experimental, or near release.</Accordion>
  <Accordion title="Where can I review storage and bandwidth?">Use the workspace usage and billing areas.</Accordion>
</AccordionGroup>
