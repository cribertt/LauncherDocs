# Add your first game

<Steps>
  <Step title="Open the launcher">Select the launcher that distributes the game.</Step>
  <Step title="Create the game">Enter title, slug, description, and genre.</Step>
  <Step title="Add images">Upload the cover and banner.</Step>
  <Step title="Configure the executable">Set the path relative to the installed build.</Step>
  <Step title="Save and verify">Confirm that the game appears in the dashboard and CLI.</Step>
</Steps>
