# Biblioteca de juegos

La biblioteca muestra juegos disponibles para el jugador.

La disponibilidad puede depender de:

- Launcher.
- Acceso al juego.
- Keys activadas.
- Permisos de rama.
- Restricciones de cuenta.
- Releases publicadas.
