# Builds and branches

| Branch | Typical purpose |
| --- | --- |
| **Stable** | Production-ready releases. |
| **Beta** | Public or limited pre-release testing. |
| **Alpha** | Early feature validation. |
| **Development** | Internal development or QA. |
| **Private** | Restricted distribution when supported by the plan. |

  <Tab title="STABLE">Complete release baseline.</Tab>
  <Tab title="PATCH">Planned update with new or modified files.</Tab>
  <Tab title="HOTFIX">Urgent focused correction.</Tab>

## Updates

Launcher Forge uses manifests and SHA-256 hashes to compare content and download the files required by a new version.

## Version history

Each version should record its number, branch, release type, changelog, date, processing state, and manifest.
