# Unreal Engine integration

<Steps>
  <Step title="Install the plugin">Add the Launcher Forge plugin to a supported Unreal Engine project.</Step>
  <Step title="Enable the plugin">Restart the editor when required.</Step>
  <Step title="Configure Game Instance">Initialize authentication during startup.</Step>
  <Step title="Wait before validation">Keep the recommended `0.5` second startup delay.</Step>
  <Step title="Validate asynchronously">Use the asynchronous launch-token validation flow.</Step>
</Steps>

## Launch contract

```text
MyGame.exe --launchToken=TOKEN
```

## Successful validation

```json
{
  "id": "player-id",
  "email": "player@example.com",
  "valid": true
}
```

## Shipping builds

- Do not expose Token Override.
- Do not print raw launch tokens.
- Do not depend only on development logs.
- Show a controlled error when authentication fails.
