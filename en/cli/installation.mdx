# Install the CLI

The Launcher Forge CLI is menu-driven. It does not require long deployment commands.

<Steps>
  <Step title="Download the official CLI">Use the download provided by Launcher Forge.</Step>
  <Step title="Extract the package">Uncompress the archive when required.</Step>
  <Step title="Open a terminal">Open PowerShell, Windows Terminal, or another supported terminal.</Step>
  <Step title="Run the executable">Start the Launcher Forge CLI.</Step>
  <Step title="Authenticate">Complete the interactive login when no valid session exists.</Step>
</Steps>
